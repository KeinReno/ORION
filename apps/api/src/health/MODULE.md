# Здоровье (`health`)

Личный журнал здоровья: люди (вы и те, кого вы ведёте), визиты, профилактика и прививки, лекарства, измерения и симптомы.

Записи принадлежат человеку (`subjects/:subjectId`) и видны другим участникам только по явному допуску. Врачи — обычные контакты.

Полностью самостоятелен. Контакты нужны только чтобы выбрать врача.
