# ORION DEV (`orion-dev`)

Рабочее пространство разработки в ORION: обзор и безопасный импорт каталога,
архитектурная карта зарегистрированного репозитория, сверка проектного замысла
с распознанным кодом и история Git только для чтения.

Не требует запущенных агентов или внешнего AI API.

## Архитектура и Git

Web-панель `apps/web/modules-ext/orion-dev/ArchitectWorkbench.tsx` использует
публичные типизированные контракты `@orion/shared-types` и маршруты модуля
`workspaces/:workspaceId/development`. Репозиторий сначала регистрируется
владельцем/руководителем внутри разрешённых серверных корней. Браузер передаёт
только ID регистрации, не файловый путь для выполнения команд.

Карта строится серверным анализатором; пользовательская раскладка хранится
отдельно и обновляется по ревизии. Проектная схема также хранится отдельно от
исходников и сверяется с текущим анализом. Git-поверхность показывает только
историю, ветки и теги; запись в Git отсутствует. Результат анализатора является
эвристическим наблюдением, не доказательством полноты или корректности кода.
