# Architect (`orion-dev`)

Рабочее пространство Architect в ORION: визуальные процессы (схемы из задач,
агентов, доказательств, решений и результата), архитектурная карта
зарегистрированного репозитория, сверка проектного замысла с распознанным кодом
и история Git только для чтения. Проектно-нейтрально: не привязано к каталогу
разработки ORION и не требует предзаполненных данных.

Не требует запущенных агентов или внешнего AI API.

## Архитектура и Git

Web-панель `apps/web/modules-ext/orion-dev/ArchitectWorkbench.tsx` использует
публичные типизированные контракты `@orion/shared-types` и маршруты модуля
`workspaces/:workspaceId/development`. Репозиторий сначала регистрируется
владельцем/руководителем: существующая рабочая копия git подключается по пути,
а пустая или новая папка внутри разрешённых корней превращается в репозиторий
одним действием (`git init` на узле). Браузер передаёт
только ID регистрации, не файловый путь для выполнения команд.

Карта строится серверным анализатором; пользовательская раскладка хранится
отдельно и обновляется по ревизии. Проектная схема также хранится отдельно от
исходников и сверяется с текущим анализом. Git-поверхность показывает только
историю, ветки и теги; единственная запись — явное создание репозитория при
регистрации. Результат анализатора является
эвристическим наблюдением, не доказательством полноты или корректности кода.
