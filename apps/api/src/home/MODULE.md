# Дом (`home`)

Дом: квартира, дом, дача, машина как объекты, их счётчики и показания; задачи, списки, вещи, платежи и контакты остаются в своих модулях и лишь привязываются к дому.

Контроллер отдаёт `workspaces/:workspaceId/homes`; коммунальные расчёты вынесены в соседний каталог `home-utilities/`.

Работает без задач, списков, склада и финансов — соответствующие блоки на странице дома просто не показываются.
