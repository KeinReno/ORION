# Привычки (`habits`)

Привычки и ежедневные отметки. Отметка — день (`@db.Date`), идемпотентная по паре привычка-день.

Серия и признаки «на сегодня» вычисляются функциями из `shared-types/src/habit.ts`, в базе не хранятся. Удаление привычки архивирует её.

Полностью независим от остальных предметных модулей.
