# KAIDEN Orion Android

## Platform
Android package with a dedicated mobile React/WebView interface and native SQLite.
Acceptance device: OPPO Reno8 5G; OS version unverified.

## Product truth
Owner authorized implementation on 21 October 2026: local offline tasks, notes,
shared existing contracts, mobile shell and preparation for LAN.
Desktop stability and persisted data must be preserved.
Personal and small-team use share the existing workspace/permission model.
This alpha exposes only an independent local space.

## Stack
Existing TypeScript workspace; Capacitor 8 + React 18 + Vite 6, selected for
reuse of public Orion types and operation projection. Native SQLite bridge.

## Scope and authority
See docs/android in the repository. No new brand direction:
approved KAIDEN logo and existing quiet dark surfaces, with a system light theme.
Mode: Operate. Main flow: capture, edit, resume offline.
