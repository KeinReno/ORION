# 07 — Заметки 2.0 (backend)

**Зона ответственности:** `apps/api/src/notes/**`, Prisma-блок `BEGIN 07`,
миграции, тесты notes. **Волна:** 2. **Никакого фронтенда.**
Локальные документы: `docs/NOTES_2.0.md`, `docs/AI_REFACTOR_MIGRATION_MAP.md`
(раздел 6 Notes).

## Контекст

Уже есть: `Note`, `NoteLink` (внутренние ссылки), `NoteRevision`, `NoteAttachment`,
серверные визуальные стопки (выбор, порядок, перемещение — реализованы
09.11.2026). План (раздел 6 переписки): версии, вики-ссылки, поиск внутри
заметки, связанные заметки.

## Задачи

### 7.1. История версий

- Дополнить `NoteRevision`: restore endpoint (восстановление = новая ревизия
  с содержимым выбранной, пометкой restoredFrom); diff endpoint — контракт
  для фронта: список изменённых строк/блоков (простой построчный diff,
  без сторонних diff-библиотек — не добавлять зависимость); лимит хранения
  последних 50 ревизий на заметку (обрезка фоновой задачей с учётом
  module-enabled).
- Автосохранение не плодит ревизии: ревизия — на явный save/close.

### 7.2. Вики-ссылки [[...]]

- При сохранении заметки сервер парсит `[[target]]` в body: target — title
  заметки или id; создаёт/обновляет `NoteLink` записи (source→target).
- Поддержание целостности: удаление целевой заметки — ссылки сохраняются
  как «битые» (флаг на NoteLink `broken: true`), не удаляются молча; endpoint
  `GET /notes/:id/links` — исходящие+входящие с флагом broken; endpoint
  битых ссылок по workspace для разбора.
- Циклы ссылок допустимы (нет ограничения), глубина обхода при агрегации —
  ограничена (2 уровня).

### 7.3. Поиск и контракты содержимого

- `GET /notes/:id/search?q=` — offsets вхождений в body (для фронтовой
  подсветки); регистрация содержимого заметок в глобальном поиске (provider —
  по соглашению с заданием 10).
- Контракт «связанные заметки»: endpoint `GET /notes/:id/related` — через
  NoteLink + EntityLink (задание 01) + совместные проекты/задачи.

### 7.4. Стопки

- Существующая реализация стопок: добавить collapse-состояние стопки
  (per-user: `NoteStackState`), порядок стопок (per-user), лимит вложенности
  (стопки в стопках — не поддерживаются, явный отказ).

## Критерии приёмки

1. Сохранение с `[[A]]` создаёт NoteLink; переименование/удаление цели
   помечает broken без удаления записи (интеграционный тест).
2. Restore ревизии создаёт новую ревизию; история сохраняется (тест).
3. Diff endpoint возвращает корректные изменения на известной паре версий
   (тест на фикстуре).
4. Проверки из `00-README.md` зелёные; миграции с нуля PASS.
5. Отчёт-блок в `docs/STATUS.md`.

## Out of scope

Фронтенд-редактор, дневные заметки (notes-daily plugin), шаблоны
(notes-templates plugin), экспорт/импорт, бесшовный семантический поиск.
