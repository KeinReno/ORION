## Очередь

1. **P0, релиз.** Держать локальный прогон `typecheck`, `lint`, `test`, `architecture-check`, `plugin-contract-check`. CI на GitHub не чинить переписыванием тестов, пока раннер не стартует. Каждый установщик повышает версию NSIS. SHA-256 — строка в теле релиза.
2. **P0, меню.** Добить приёмку мышью и в модалке для Combobox финансов и GlideSelect статуса. Клавиатурные правила уже в `list-keyboard.ts`.
3. **P0, запреты.** Флаг `documents` теперь режет модульные инструменты. Проверить тем же способом, что другие флаги из `AGENT_FORBIDDEN` либо применяются, либо убраны из интерфейса.
4. **P1, присутствие.** Расширять `agentPresenceEventSchema` необязательными полями (`field`, `before`, `after`), не ломая старых клиентов. Пока поля нет — подсвечивать объект. Долгий журнал строить из `agentAuditEntry`, не из памяти на 2 минуты. SSE только если появится уже принятый транспорт; опрос оставить рабочим.
5. **P1, hub.** Повесить `reconcileExpired` на существующий `BackgroundJobsService`, не писать новую очередь. HTTP для `verify` — отдельное решение владельца: это не процедура QA-v2.
6. **P1, sync и LAN.** Новая синхронизируемая сущность = класс в `sync-classification.ts`, поля, адаптер, триггер, тест сходимости. Передача файлов по LAN — новый протокол поверх уже доверенного узла, не смешивать с репликой и с WebDAV.
7. **P1, Android.** Сливать #81/#82 только после сверки контрактов с текущим `shared-types`. В этом дереве клиента нет.
8. **P1, таблицы.** Дописывать `xlsx-codec` в границах documents-office. Потеря неподдержанной конструкции при сохранении должна быть явной ошибкой, не тихим успехом.
9. **P2.** Возможности, Compass, знания, остальные домашние модули — после пунктов 1–4. Внешние отклики и чужие финансовые сущности не переносить.

## Кто что не должен делать параллельно

Agent Capability, модули и права делят `permissions.ts` и `agent-tools.ts`. Правка одного без другого разъедет MCP и политику. Orion Link, Android и hybrid sync делят идентификаторы устройств и курсор реплики. Сначала карта в `ORION_PLATFORM_GAP_MATRIX_20261108.md`, потом отдельные задачи.
