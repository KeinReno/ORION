# Windows Beta 38 — агент, горячие клавиши, DOCX, 07.11.2026

Статус: опубликован GitHub prerelease beta.38. Установщик собран из `dc920eefc71a86492f50c5f61e93faf6e7ade2c7` (`codex/orion-dev-stabilization-20261102`). По просьбе владельца эта линия быстро перемотана в `master` (в beta 37 master не трогали).

## Что вошло

Поверх beta 37, без чужих незакрытых веток:

- Удаление агентом задачи, заметки и события. Администратор удаляет сразу, помощник и менеджер получают запрос, наблюдатель и запрет `delete` — отказ. Задача удаляется безвозвратно, заметка уходит в корзину, событие снимает серию. Чат ассистента этого глагола не получает. [ADR-0044](../docs/adr/ADR-0044-agent-delete-core-entities.md).
- Причина удаления из query зеркалится в тело запроса, чтобы модульные контроллеры её не теряли.
- Присутствие агента открывает запись, которую он читает или меняет, и подсвечивает строку. Координат курсора нет. Подсвечены задачи, проекты, заметки и документы. Пилюли календаря — нет: это общий компонент календаря.
- Сочетания «g, затем буква» и раскладки Alt+1…9 реально срабатывают.
- Сохранение DOCX сохраняет объединение ячеек (`columnSpan` / `rowSpan`).
