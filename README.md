## Всё важное — в одном месте

Вместо нескольких разрозненных инструментов — единое рабочее пространство. Планируйте дела, сохраняйте идеи, ведите проекты и находите нужную информацию в привычном контексте.

## Возможности

| | |
| --- | --- |
| **Задачи и проекты** | Планирование, сроки, приоритеты, подзадачи и отслеживание выполнения. |
| **Календарь** | События, расписание и напоминания. |
| **Заметки и документы** | Материалы, вложения и связанные записи. |
| **Финансы** | Учёт операций, бюджетов и финансовых целей. |
| **Рабочие пространства** | Разделение личных и совместных дел. |
| **Гибкий интерфейс** | Настраиваемое рабочее пространство и выбор нужных модулей. |

## Как устроена работа

**Соберите контекст.** Создайте пространство для личных дел, семьи или команды.

**Планируйте и действуйте.** Объединяйте задачи, события, заметки и материалы вокруг проектов.

**Оставляйте только нужное.** Используйте подходящие модули и представления, не перегружая рабочее место.

## Установка

ORION развивается прежде всего как настольное приложение для Windows.

**[Посмотреть доступные версии](https://github.com/KeinReno/ORION/releases)**

> [!NOTE]
> Проект находится в стадии активной разработки. Доступные сборки могут быть тестовыми. Перед обновлением сохраните резервную копию важных данных. Если нет подходящего опубликованного выпуска, дождитесь следующей сборки.

## Статус проекта

**Активная разработка.** Возможности и интерфейс продолжают развиваться; часть направлений пока находится на стадии экспериментов и тестирования.

### В планах

Более гибкие рабочие сценарии, развитие совместной работы, синхронизации между устройствами и интеграций с ИИ-помощниками. Планы не означают доступность функций в текущей версии.
