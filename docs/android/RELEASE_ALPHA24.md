# Android alpha.24 — совместимость данных и подтверждённая связь

Статус: HISTORICAL / проверка 26.10.2026. Исходный HEAD: e14ee02 плюс
изменения этого отчёта; точная ревизия выпуска записана в GitHub release.
Текущие факты — [STATUS](../STATUS.md), направление — [PLATFORM](../PLATFORM.md).

## Исправления

- Индикатор связи считает возраст последнего успешного обмена по монотонным
  часам текущего сеанса Android. Время `asOf` сервера остаётся метаданными
  снимка; расхождение часов устройств больше не делает связь постоянно старой.
  Загруженная с диска копия сама по себе не означает активное соединение.
  Подтверждение привязано к экземпляру клиента; очередь и конфликты имеют приоритет.
- У списка ПК удаление доступно после архивирования, как требует существующий
  серверный контракт. При возврате списка из архива с другого устройства
  открытое подтверждение удаления блокируется. Локальные списки не затронуты.
- При реальном обновлении обнаружена несовместимость старых задач с новым
  обязательным `checklist`: сначала локальный snapshot, затем кэш пространства
  не открывались. Добавлена узкая схема чтения в mobile-core для snapshot,
  replica и переносимых backup: только отсутствующее поле получает `[]`.
  Некорректный checklist по-прежнему отклоняется; данные не сбрасываются.
  Публичная схема Task и wire-контракты не менялись.
- Fixture проверки обновлений вычисляет будущую версию из текущей, чтобы
  релиз не превращал тестовое «будущее обновление» в уже установленное.

## Проверки

Windows 11, JDK21, Android SDK36; OPPO Reno8 5G CPH2481 / Android15, Wi-Fi ADB.

- До миграции: 101 профильный тест Android/mobile-core/core sync, lint,
  architecture-check и 11 plugin-contract tests прошли.
- После миграции: 64 tests mobile-core/индикатора прошли, включая сохранность
  локальных задач, queued edit в старой replica, старый backup и отказ от
  некорректного checklist без перезаписи диска.
- Полный typecheck прошёл после окончательного изменения; профильный lint —
  без ошибок. Android web build, cap sync, assembleDebug, assembleRelease,
  lintDebug и testDebugUnitTest прошли повторно.
- Browser: списки CRUD/перезапуск/черновики/backup/320px, настройки и manifest,
  archive prerequisite и concurrent unarchive guard прошли. Компонентный fixture
  находится в tests, не входит в production Vite entry.
- Физическое обновление alpha.23 → alpha.24 выполнено через `adb install -r`.
  Полный snapshot до/после совпал с единственным добавлением `checklist: []`
  у 7 старых задач; 1 локальная заметка, финансы, настройки, черновики и identity
  сохранены. Секреты и содержимое снимков не публикуются.
- Существующая привязка к Windows beta.25 восстановилась без повторного pairing.
  Индикатор показал «ПК ответил · очередь пуста» при расхождении часов ~78 секунд.
- Новый синтетический список/пункт с OPPO автоматически появились в открытом
  desktop. Клик по пункту в desktop автоматически отобразился на OPPO без
  ручного sync. Через Android список отправлен в архив и удалён; подтверждено
  pending=0, conflicts=0, списков в replica=0. Исходная задача ПК сохранена.

## Границы и следующие проверки

Это foreground LAN sync задач/заметок/списков. Постоянный фоновый обмен,
синхронизация финансов, сценарии двух ПК, смены Wi-Fi/VPN и длительного сна
не подтверждены этой приёмкой. Архивирование остаётся обязательным для удаления
общего списка. Windows-файлы и серверные контракты в этом изменении не менялись.
Следующий этап — повторяемая проверка обрыва/возврата сети и сна ColorOS,
затем отдельное проектирование синхронизации финансов.
