# KAIDEN Orion Mobile — alpha.29 (0.1.28)

## Состав этой альфы

- **Living Cosmos:** тёмное орбитальное пространство за UI, мягкая пульсация света и графитовая текстура некоторых карточек.
- **Режимы:** выключено / тихое / выразительное, в разделе «Настройки → Движение и жесты». Выбор сохраняется только на этом телефоне.
- **Послойность:** фон движется независимо, кнопки и текст сохраняют стабильную геометрию. Используется существующий Android-датчик наклона. Reduced Motion и неактивное приложение приостанавливают анимации.
- **Сегодня:** обзор приоритетной задачи, сегодняшних дел, быстрый переход в календарь и создание задачи.
- **Календарь:** день / неделя / месяц на реальных локальных/доступных синхронизируемых задачах, с отдельным показом начала работы и дедлайна. Кнопка открытия задачи ведёт в полноэкранный редактор.
- **Задачи и заметки:** существующие полноценные экраны редактирования сохранены; не заменяются выдвижными панелями.
- **Опциональные жесты:** выключены по умолчанию. Вправо — выполнить/вернуть задачу, закрепить заметку. Влево — скрыть запись на 6,5 секунды с возможностью отменить перед необратимым удалением. При включённых жестах сохраняются обычные кнопки и меню.
- **Связь:** штатные уведомления не перекрывают список, предупреждения об ошибках остаются доступными; точное состояние доступно по индикатору в шапке.
- **Порядок модулей:** Сегодня / Задачи / Календарь / Заметки / Ещё. Финансы и Списки доступны в «Ещё».
- **Оффлайн:** локальные записи и очереди обмена не удаляются и не переписываются ради редизайна.

## Ограничения альфы

1. Календарь отображает **задачи**, не полный десктопный календарь событий. Работу с внешними календарями и отдельными событиями предстоит добавить.
2. Плановое начало `startAt` и дедлайн `dueAt` различаются; при отсутствии `startAt` случайный временной слот не назначается.
3. Отмена жеста удаления доступна **до** отправки операции удаления через 6,5 секунд. После этого шага восстановление требует резервной копии.
4. Android WebView не гарантирует наличие Battery Status API. Reduced Motion и пауза приложения работают отдельно.
5. CI GitHub Actions не запускал build runner из-за ограничений аккаунта. **Готовый APK и успешное выполнение TypeScript/Gradle/тестов не подтверждены.** Альфа пока только в исходном коде.

## Сборка на Windows без GitHub Actions

Ветка: `feat/android-living-cosmos-alpha29`.

Зависимости: Git, Node.js с pnpm (рекомендуется 9.12.0), JDK 21, Android Studio / SDK Platform 36 / Android Build Tools, доступ к npm и Maven (при необходимости через VPN).

Из PowerShell в корне существующего клона Orion:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\android-build-local-alpha29.ps1 -RepoPath "C:\Users\gvi\Desktop\ORION"
```

Скрипт создаёт **отдельный worktree**, не меняя текущую рабочую копию. APK после успешного выполнения: `KAIDEN-Orion-0.1.28-android-alpha.29-debug.apk` рядом с каталогом сборки.

**Подпись:** debug APK может иметь другой сертификат, чем установленная alpha.28. Не удаляйте предыдущую версию с данными, пока не сделан экспорт резервной копии в самом Orion. Для обновления поверх неё необходим тот же подписывающий ключ.

## Ручная проверка на OPPO Reno8 5G

1. Включить/выключить «Живой фон», проверить тихий и выразительный режимы и светлую тему.
2. Наклонить телефон: декоративный фон смещается, текст и кликабельные элементы остаются на месте.
3. Проверить режим «Уменьшить анимацию», уход приложения в фон, возвращение и длительную прокрутку.
4. Создать задачу с `startAt`, `dueAt`, длительностью; проверить календарь (день/неделя/месяц).
5. Открыть задачу из календаря, вернуться назад, убедиться, что черновик не потерян.
6. Включить свайпы; вправо завершить задачу, влево удалить и успеть отменить; повторить и дождаться удаления.
7. Закрепить заметку свайпом вправо; удалить с отменой; проверить обычные кнопки при выключенных жестах.
8. Проверить списки, финансы, экспорт резервной копии и синхронизацию с ПК / офлайн-работу.

Любые ошибки сборки или работы на устройстве нужно приложить к PR #82.
