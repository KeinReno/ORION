# Концепция Android alpha

## Задача пользователя
Быстро записать мысль или задачу на телефоне, прочитать и изменить её без сети.
Результат: запись переживает закрытие приложения и перезапуск телефона.
Сегодня отдельного Android-клиента в репозитории нет.
Действия затрагивают только локальное пространство телефона; передачи другим
пользователям в alpha нет. Это явно видно в интерфейсе.

## Мобильная поверхность
Три назначения: «Задачи», «Заметки», «Связь». Список → полноэкранный редактор →
возврат в тот же раздел. Кнопка создания рядом с заголовком; системный Back
возвращает из редактора. Черновик сохраняется отдельно от готовой записи.
Задачи: название, описание, статус, приоритет. Заметки: название и Markdown
как исходный текст, без потери разметки. Поиск работает локально.
Архивирование заметки обратимо; завершение задачи обратимо.
Тёмная и светлая схемы следуют системной теме, сохраняют акцент KAIDEN.

## Состояния и решения
| Сценарий | Поведение | Основание product-design |
|---|---|---|
| Первый запуск | Пустое локальное пространство, создание без регистрации | rule/value-before-interruption |
| Нет записей / нет совпадений | Разные сообщения, доступное создание / сброс поиска | rule/empty-state-action |
| Сохранение | Успех только после записи на диск, ошибка оставляет текст | rule/preserve-user-input |
| Закрытие редактора | Отдельный черновик; явная отмена очищает только его | rule/name-object-scope-consequence |
| Хранилище недоступно / повреждено | Ошибка и повтор, без сброса данных | rule/error-states-recovery |
| Нет сети | Все локальные действия доступны, никакого ложного «синхронизировано» | rule/cover-reachable-states |
| Длинный текст, клавиатура | Прокрутка редактора, переносы, цели касания 48px | rule/accessible-name-required |

Полный desktop, ИИ, финансы, push, фоновые сервисы, документы и установка
плагинов не входят в alpha. Персональная и командная работа остаются равноправны
в целевой архитектуре: будущий вход выбирает разрешённое workspace, а не
создаёт отдельную модель «командного приложения».
