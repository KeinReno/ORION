# Android alpha.22 — задачи, заметки, финансы

26.10.2026 · Android 0.1.21 / code22. Исторический отчёт этого изменения.
Устройство: OPPO Reno8 5G (CPH2481), Android15, физический экран1080×2400.
Направление: PLATFORM Stage0, FRONTEND_WORKSPACE_SPEC, mobile MODULE_SURFACES.

## Продуктовое решение

Пользователь хочет быстро найти/открыть запись и внести расход; сейчас высокая
панель фильтров отодвигает содержимое. Фильтры остаются inline и раскрываются
по запросу (rule/inline-before-modal, rule/structure-before-containers).
Сворачивание не меняет фильтры; их число и сброс видны снаружи.
Действия касаются текущего списка/пространства и не меняют данные/права.
Удаление по-прежнему требует именованного подтверждения; ввод сохраняется
при ошибках (rule/name-object-scope-consequence, rule/preserve-user-input).
Успех: первая задача доступна без прокрутки панели настроек, исходный Markdown
сохраняется, финансовая операция быстро вносится и редактируется без дубликата.

## Изменения

- Задачи: быстрые фильтры «Все / Открытые / Сегодня», компактная раскрывающаяся
  панель порядка/фильтров, отдельные метки срока и приоритета, читаемый статус.
  «Открытые» включает все незакрытые статусы; исходная ручная сортировка сохранена.
- Заметки: компактные фильтры; Markdown-превью очищается токенизатором только
  для отображения. Хранимый исходник/summary не меняются; код и подписи изображений
  остаются текстом. Карточка и её дополнительные действия получили ясную геометрию.
- Финансы: расход/доход перед суммой, единая поверхность формы, категории,
  компактный месяц истории, расходы/доходы/разница выбранного месяца. Разница —
  не баланс счёта. Схема и расчёты сумм в целых копейках сохранены.
- Уведомление связи занимает компактную строку с доступной кнопкой перехода.
  В финансах оно не дублирует уже показанное объяснение локального хранения.
- На физическом Android15 обнаружено наложение прокрученного текста на статусбар:
  добавлен фон safe-area и отступ sticky-панели редактора.

Общие цвета из существующих theme tokens; нижняя навигация с иконками.
Наклоны и модель личных/общих пространств не переосмыслялись.
Десктопные исходники, БД-схема и публичные sync-контракты не менялись.

## Ограничения

Финансы пока локальны. Обмен задач/заметок/списков работает в foreground для
явно выбранного hybrid-пространства; локальные записи не импортируются сами.
На телефоне обнаружено сохранённое сопряжение/вход, но пространство Kaiden
ещё не hybrid: выбор корректно показывает инструкцию вместо ложного успеха.
Отдельная фактическая проверка LAN будет записана после включения режима владельцем.
USB ADB не появился; аппаратная проверка проведена по Wi-Fi ADB.
Два ПК, VPN-маршруты, фоновый обмен и новый Windows-установщик не проверены/не выпущены.
JS bundle всё ещё выдаёт предупреждение размера (Markdown parser добавлен в preview).

## Следующие шаги

Включить hybrid на ПК, загрузить ту же рабочую область, проверить доставку
тестовой правки в обе стороны и очередь после потери связи. Физическое UI QA
не подменяет эту сетевую приёмку. Для receipt OCR нужен отдельный plugin proposal.
