# Android — восстановление из резервной копии

Реализовано 22.10.2026; вошло в alpha.17 (0.1.16/code17). Срез использует
существующий формат `kaiden-orion-android-backup` версии 1 и публичные модели
`@orion/shared-types`.

## Что делает пользователь

В «Настройки → Данные и резервные копии → Восстановление из копии» выбирается
JSON-файл, ранее сохранённый через «Сохранить резервную копию». До любой записи
Orion проверяет файл и показывает: имя файла, дату создания, число задач,
заметок, списков, пунктов списков и финансовых операций, а также есть ли в файле
копия пространства ПК.

Затем выбирается один из способов:

- **Добавить недостающие** — добавляет записи, чьих `id` ещё нет на телефоне;
  существующие записи, черновики, очередь изменений и порядок задач не
  меняются. Ничего не удаляется.
- **Заменить записи** — локальные задачи (включая чек-листы), заметки, списки и
  финансы становятся такими, как в файле. Способ требует встроенного
  подтверждения с текущими счётчиками; отменить замену после записи нельзя.

Файл читается нативным `ACTION_OPEN_DOCUMENT` (Android) или `<input type=file>`
(браузерная проверка). Отказ от выбора не меняет данные. Повреждённый файл,
чужой формат, файл больше 24 МБ и повторяющиеся идентификаторы отклоняются до
записи с русским объяснением.

## Что сохраняется при восстановлении

Оба способа не трогают `workspaceId`, `deviceId`, `deviceSeq`, HLC-часы,
настройки, LAN-сопряжение, выбранные удалённые пространства и локальную копию
данных ПК. Импортированные записи переносятся в текущее пространство телефона.

- Настройки, тема, наклон, обновления и параметры LAN остаются телефонными.
- Содержимое `remote` в файле только показывается как факт; оно не заменяет
  копию пространства ПК и не отправляется на компьютер.
- Незавершённый ввод на телефоне сохраняется. Черновик из файла подставляется
  только в пустой слот и только если запись, к которой он относится, существует.
- Балансы счетов пересчитываются из восстановленных операций.

### Замена

- Очередь локальных изменений (`outbox`) очищается: старые операции относятся к
  заменённым записям и не должны уйти на компьютер.
- Порядок задач телефона очищается; порядок удалённого пространства не
  затрагивается.
- Метка последней отправленной копии (`lastBackupSeq`) сбрасывается, поэтому
  следующая синхронизация заново сверит локальные задачи и заметки.
- Если в файле нет финансового раздела, текущие финансы остаются как были.

### Добавление недостающих

- Списки с совпадающим `id` пропускаются целиком, в том числе если совпал
  `id` хотя бы одного пункта.
- Финансовые операции пропускаются, если их `id` уже есть или если после
  добавления отсутствует нужный счёт/категория.
- Если ничего не добавлено, `lastBackupSeq` не меняется; иначе сбрасывается.
- Повторное добавление той же копии идемпотентно.

## Проверки

- `packages/mobile-core`: 4 теста восстановления — валидация и отклонение
  повреждений; merge добавляет только недостающее, переносит пространство и
  сохраняет identity/настройки/сопряжение/черновик/порядок; replace заменяет
  записи, очищает очередь и порядок телефона, сохраняет настройки и черновик,
  переживает повторное открытие репозитория; ошибка записи на диск оставляет и
  снимок, и файл без изменений. Весь пакет — 50 тестов PASS.
- Browser smoke `scripts/android-restore-smoke.mjs`: неверный файл отклоняется
  до записи; предпросмотр; замена с подтверждением восстанавливает задачи,
  чек-лист и финансы; добавление возвращает удалённое и не трогает текущее;
  данные переживают reload; нет горизонтального переполнения и ошибок страницы.
- `vitest run packages/mobile-core`, остальные Android browser smoke,
  точечный ESLint, `architecture-check`, сборка и `android:sync` PASS.
- `assembleDebug`, `lintDebug` (0 errors), `testDebugUnitTest` PASS.
- GitHub Actions недоступны из-за платёжного ограничения аккаунта; проверки
  локальные.

## Ограничения

- Физический выбор файла через SAF на OPPO Reno8 5G/ColorOS не проверен;
  браузерный file picker не доказывает поведение системного проводника.
- Восстановление не переносит настройки, LAN-сопряжение и копию пространства
  ПК и не удаляет данные на компьютере.
- Нет выборочного восстановления отдельных записей, слияния по полям,
  автоматической резервной копии перед заменой и отмены замены.
- Формат версии 1; файлы другой версии отклоняются, миграции формата нет.
