# ORION-12 — AI Bridge: диагностика недоступности ассистента

> **Статус:** APPROVED BACKLOG / к технической сверке, не реализовано этим документом. **Дата согласования:** 27.10.2026. **Приоритет:** P1. **Область:** Ассистент/API/состояние узла.  
> **Источник:** наблюдение пользователя в установленном Orion и согласование продуктовых решений. Техническая причина и соответствие текущему HEAD пока не установлены.

## Проблема

Пользователь видит «Мост для агентов выключен на этом сервере (ORION_AI_BRIDGE=1 включает)» и не может понять путь восстановления.

## Задачи для реализации

- Проверить режим узла, значения/источники конфигурации, feature flags и реальную причину выключения bridge.
- Развести состояния: выключено политикой, недоступен API, не подключён агент, нет прав, ошибка инициализации.
- В UI статус + безопасные шаги диагностики/настройки в пределах полномочий администратора.
- Сохранить ограничение доступа: конфигурация моста не включается по умолчанию без проверки рисков.

## Критерии приёмки

1. Причина недоступности объясняется конкретно, без технического тупика; статусы различимы.
2. Включение при соответствующих полномочиях отражается корректно, отказ безопасен.
3. Запрещённый bridge не открывает обхода авторизации.

## Зависимости

AI Gateway/Manager, конфигурация server/local, RBAC.

## Риски / ограничения

Не превращать `ORION_AI_BRIDGE` в небезопасный переключатель без политики.
