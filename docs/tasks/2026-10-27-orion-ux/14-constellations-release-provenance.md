- Ввести smoke проверку: принятые правки отображаются в реальной установленной сборке.

## Критерии приёмки

1. Есть воспроизводимая запись: installed UI/API commit → release artifact → repository commit.
2. Подтверждено, почему пользователь не видит изменения, с конкретным исправлением или инструкцией обновления.
3. В будущих сборках provenance проверяется автоматически.
