# ORION-16 — Архив чатов: автоматические источники Codex/Cursor/Qoder/Claude Code

> **Статус:** APPROVED BACKLOG / к технической сверке, не реализовано этим документом. **Дата согласования:** 27.10.2026. **Приоритет:** P2. **Область:** Архив чатов/интеграции.  
> **Источник:** наблюдение пользователя в установленном Orion и согласование продуктовых решений. Техническая причина и соответствие текущему HEAD пока не установлены.

## Проблема

Сегодня архив пуст и предполагает ручной импорт. Требуется автоматическое подтягивание истории доступных локальных агентов.

## Задачи для реализации

- Матрица реальных форматов и доступности для Codex, Cursor, Qoder, Claude Code в CLI и расширениях VS Code/Cursor; не заявлять универсальный экспорт заранее.
- Адаптеры источников, opt-in обнаружение локальных сессий, incremental sync, идентичность и дедупликация.
- Отдельные поля: агент/провайдер, host IDE, проект/репозиторий, session ID, дата и provenance; полнотекстовый поиск и фильтры.
- Контроль разрешённых папок, исключение секретов, управление retention и ручной импорт как fallback.

## Критерии приёмки

1. Одна и та же сессия не дублируется при повторном импорте или из разных путей.
2. Можно отличить Claude Code в Cursor от standalone Claude Code, если данные источника это позволяют.
3. Отключение источника прекращает сбор и не удаляет историю без явного действия.

## Зависимости

Архив чатов как module/plugin через публичные контракты, локальная файловая безопасность.

## Риски / ограничения

Форматы и доступы третьих продуктов нестабильны; не сканировать скрытые/чужие данные без согласия.

3. Для новых API, capabilities, прав или границ Core/Module/Plugin — сначала согласовать публичные контракты/ADR; не импортировать internals другого модуля.
