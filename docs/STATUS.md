## Проверено на этой ревизии (облачная среда, Linux)

CI на каждом PR зелёный: typecheck, lint, architecture-check, plugin-contract-check, unit-тесты, `test:integration` на чистой PostgreSQL после всех миграций, build, полный e2e и `build:desktop-export`. Локально: `pnpm test` — 1173 теста; `pnpm test:e2e:local` — 122 из 124 (два сценария импорта папки HH в Opportunity Hub не проходят только в облачном Chromium — он не передаёт выбранную папку; в CI проходят).

**Не проверено:** Tauri-окно и установщик на Windows (в облаке нет Rust/WebView2), открепление окон, несколько мониторов и DPI, LAN между двумя реальными машинами, гибридная синхронизация между устройствами.

## Не сделано и известные пробелы

**Этап 0.** Пять экранов ТЗ 01–05 переведены. Остальные модули и плагины в новом виде и при смене темы глазами не проверены (волна 2.4). История переходов, прокрутка и черновики после аварийного закрытия не переживают перезапуск. «Потрачено» в карточке проекта (`ProjectsService.spentAmount`) складывает расходы в разных валютах — нужно решение владельца (фильтр по `Project.currency` обнулит пространства со счетами в USD).

**Этапы 2–3 (по аудиту).** Контракты описаны, но в коде пока нет: шины доменных событий (G3, ADR-0019 не принят), единого реестра разрешений и `@RequirePermission` (G12), правила против прямых обращений модулей к чужим таблицам (G4), динамической регистрации модулей (G5), жизненного цикла компонента (G6), изоляции ошибок фоновых задач на сервере (G9). Порядок — [PLATFORM_AUDIT.md](PLATFORM_AUDIT.md).

**Opportunity Hub.** Внесён снимком незакоммиченного состояния; ревью и живой проверки не было. Состояние — [OPPORTUNITY_HUB_PROGRESS.md](OPPORTUNITY_HUB_PROGRESS.md).

**Выпуск.** Установщика с этой ревизии нет: Tauri собирается только на машине с Rust. Сборка: `pnpm install`, `pnpm build`, `pnpm build:desktop-export`, затем `pnpm --filter @orion/desktop tauri:build`; проверять на отдельной учётной записи Windows, не трогая рабочий каталог `com.orion.desktop`.
