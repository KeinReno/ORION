# ADR-0027: синхронный мост Tasks → Time при закрытии задачи

Статус: принято для следующего сокращения межмодульных зависимостей, 25.10.2026.

NEW_EXTENSION_POINT_REQUIRED: TasksService.updateTx напрямую читает и изменяет TimeEntry.
Миграционная карта уже относит Tasks ↔ Time к Module Bridges. Перевод в асинхронный
outbox изменил бы поведение: ответ на закрытие задачи приходил бы раньше остановки таймера.

Tasks публикует узкий серверный контракт `tasks/public/task-closure-registry.ts`:
`TaskClosureRegistry.closeTx(tx, {workspaceId, taskId})`. Независимый Nest-модуль этого
контракта не импортирует TasksService, Time или другие конкретные модули. Tasks вызывает
его только после успешного изменения открытого статуса на закрытый; прежний outbox
`tasks.task.closed` остаётся независимым механизмом уведомления после commit.

Time регистрирует собственный bridge-handler, проверяет своё effective enabled-состояние
и пишет только собственные TimeEntry с обязательным workspaceId. Сохраняется существующий
алгоритм: остановить первый найденный работающий таймер этой задачи; endedAt строго позже
startedAt (минимум 1 секунда при будущем startedAt). Множественные таймеры команды этим
переносом не переосмысливаются. Выключенный Time пропускает обработчик; пустой registry
позволяет Tasks работать без установленного Time. Выключение не удаляет записи.

Обработчики идут последовательно в исходной транзакции, без внешних эффектов, собственной
транзакции или смены RLS. Ошибка откатывает задачу, таймер, activity и outbox вместе.
Проверку прав и принадлежности задачи выполняет инициатор; регистрация обработчика
не выдаёт полномочий. Повторное закрытие уже закрытой задачи не вызывает контракт.

Приёмка: HTTP-переходы done/canceled, выключенный и отсутствующий Time, чужое пространство,
конфликт ревизии и rollback позднего handler, сохранение длительности остановленной записи.
Удаляется TimeEntry из исключений Tasks, обновляется карта возможностей; остальные долги
Tasks/Time остаются явно видны. Новый контракт аддитивный: Integration API 1.2.0,
Platform API 1.3.0. UI, schema, миграции и права не меняются.
