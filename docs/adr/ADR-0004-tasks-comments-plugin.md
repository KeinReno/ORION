# ADR-0004 — Комментарии к задачам: отдельный плагин `tasks-comments`, а не часть `team`

Статус: **реализовано в коде, формальное утверждение владельцем не документировано** (не считать ACCEPTED без решения). Дата исходного предложения: 2026-10-10. Действующее поведение — отдельный `tasks-comments` с `defaultEnabled: true`.

## Контекст

`docs/AI_REFACTOR_MIGRATION_MAP.md` §5.2 относит комментарии к задачам к ownership плагина `team`, «если только отдельный `tasks-comments` не принят ADR». У `team` значение `defaultEnabled: false`, а комментарии сегодня видны у всех пространств «из коробки».

## Решение (применено в коде, откатывается одним коммитом)

Комментарии вынесены в отдельный плагин `tasks-comments` с `defaultEnabled: true`:

- правило «default-full parity» (карта §2.1): то, что видно без установки, остаётся видимым;
- привязка к `team` отключила бы комментарии у каждого существующего пространства при обновлении;
- от `team` остаются исполнитель, «Мои задачи» и роли.

## Последствия

- Если владелец решит, что комментарии — часть командной функциональности, нужно: перенести вклад `tasks.detail.tabs` под `pluginId: "team"` и сделать миграцию, включающую `team` тем пространствам, где комментарии уже есть. Данные при этом не меняются.
- Серверная часть (CRUD комментариев, уведомление исполнителю) остаётся в модуле задач: плагин управляет только интерфейсом.
