# ADR-0026: перенос межмодульных ссылок в общей транзакции

Статус: принято для первого сокращения зависимости Contacts → Capture, 25.10.2026.

NEW_EXTENSION_POINT_REQUIRED: при объединении контактов Contacts напрямую меняет anchorId чужих Capture. Асинхронное событие разорвало бы атомарность: исходный контакт уже удалён, а ссылка ещё старая.

Добавляется серверный публичный `EntityReferenceRegistry` в Core: домены регистрируют обработчики `moveTx(tx, {workspaceId, entityType, fromIds, toId})`. Core не знает конкретные модели. Обработчики выполняются последовательно в транзакции вызывающего, без новых транзакций и переключения RLS-ролей; исключение откатывает всю команду. Инициатор проверяет права и принадлежность объединяемых сущностей до вызова; каждый владелец ссылок ограничивает запрос workspaceId.

Первый потребитель — Contacts.merge; Captures регистрирует собственный перенос anchors. Остальные домены пока не переводятся. Выключенные/отсутствующие UI-плагины не влияют на целостность сохранённых ссылок. Отключение или удаление данных не является побочным эффектом переноса.

Приёмка: существующее объединение сохраняет parity; перенос Capture выполняется атомарно, чужие пространства не меняются; ошибка последующего обработчика откатывает контакт и anchors. Исключение Capture удаляется из архитектурного allowlist Contacts.
