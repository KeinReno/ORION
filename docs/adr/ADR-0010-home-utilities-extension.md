# ADR-0010 — Коммунальные начисления как расширение «Дома»

Статус: принято для реализации 14.10.2026 по запросу владельца. Основание — [HOME_EXPERIENCE_SPEC.md](../HOME_EXPERIENCE_SPEC.md).

## Контекст

Базовый `home` владеет объектами и счётчиками; `finance-obligations` хранит повторяющийся плановый платёж. Ни один из них не хранит меняющуюся сумму счёта поставщика за конкретный месяц. Семейный центр должен работать и без коммунального учёта.

## Решение

**NEW_EXTENSION_POINT_REQUIRED.** Базовый экран объекта публикует типизированный слот `home.object.tabs`. Расширение `home-utilities` (по умолчанию включено для нового целевого опыта) регистрирует вкладку «Коммуналка». При выключении вкладка и API исчезают, а записанные месяцы и тарифы сохраняются. Base не импортирует файлы расширения и не знает его таблиц.

Расширение владеет месяцами начислений и тарифами. Месяц содержит квартирную плату и строки поставщиков с суммой и статусом черновик/подтверждено. Итоги всегда вычисляются из сохранённых строк. Копирование прошлого месяца создаёт только черновые строки. Показания счётчиков читаются через публичный контракт `home` и используются для оценки; оценка не записывается как счёт или финансовая операция.

Первый срез не автоматически создаёт проводки в Финансах. Для учёта фактической оплаты нужен отдельный публичный мост к транзакциям с поддержкой частичной оплаты и явным выбором счёта. До появления этого моста UI не выдаёт начисление за оплату.

## Контракт слота

`home.object.tabs`: props `{ workspaceId, home, overview }`; meta `{ tabId, label }`. Хост рисует вкладку и передаёт контекст, компонент расширения сам загружает свои данные. Вкладка не существует при выключенном плагине. Базовый обзор остаётся работоспособным без неё.

## Миграция и сохранность

Новые данные не переписывают `FinanceObligation`, `Meter` или старые показания. Новые таблицы получают `workspaceId`, RLS и включение в оба механизма резервного копирования. Удаление объекта удаляет его коммунальную историю только после предупреждения пользователя; отключение расширения данные не удаляет.
