# Запуск пяти чатов Grok в Cursor без отдельных веток

## Перед запуском
Новые ТЗ созданы в GitHub `master`. **Локальная копия автоматически не получает их**: обновите рабочую копию безопасно до этих изменений. Если есть незакоммиченные файлы или локальные непубликованные коммиты, не запускать бездумный `git pull`; сначала сверить `git status`/`git log` и корректно согласовать историю. Никаких `reset --hard` / `clean` / массового stash для «освобождения» каталога.

Cursor: открыть одну и ту же рабочую папку Orion. Запустить пять отдельных чатов, но помнить: они меняют один набор файлов. Держать общий Git/CI/Build под одним координатором.

## Рабочая дисциплина
1. Не передавать всем чатам одну расплывчатую цель «полностью переделай Orion».
2. Координатор подтверждает ownership перед изменениями; каждый чат в самом начале перечисляет целевые файлы.
3. Каждый чат показывает локальную проверку, не выдавая прогон общего suite за свой.
4. Общие вопросы/конфликты передавать координатору; **не запускать шестой чат**, который «быстро поправит общий CSS» одновременно.
5. После пяти отчётов приостановить записи, последовательные проверки из `06_ACCEPTANCE_AND_REPORTS.md`, затем новые волны из `07_NEXT_WAVES.md`.
