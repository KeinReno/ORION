## Практический запуск
1. Открыть текущий Orion в Cursor, убедиться, что нужные изменения уже локально доступны. Создать **пять чатов в этом же проекте**; ветки НЕ создавать.
2. Каждому чату дать команду: «Прочитай `docs/KAIDEN_REDESIGN_CURSOR_5_AGENTS_2026-10-17/README.md`, `00_SHARED_TREE_PROTOCOL.md`, `06_ACCEPTANCE_AND_REPORTS.md` и **свой** файл 01–05. Исполни только своё ТЗ от аудита до отчёта. Не трогай чужие файлы и общие области. Не делай git commit/push/checkout; сообщай блокировки».
3. До правок каждый чат заполняет в собственном отчёте краткий аудит «что уже есть / что не хватает» — реализацию не дублировать.
4. Чаты могут работать параллельно **над своими файлами**; общий тестовый конвейер, миграции и git-операции запускаются последовательно одним координатором.
5. После каждой законченной вертикали — модульная приёмка. После всех пяти — полная проверка и интеграция без потери локальной работы.
