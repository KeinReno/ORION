```text
git show da8e1e1:docs/PLAN.md
git show da8e1e1:docs/RELEASE_NOTES.md
git show da8e1e1:docs/UI_UX_DESIGN.md
git show da8e1e1:docs/SONNET_IMPLEMENTATION/27-U09-THREAT-MODEL.md

Перед изменением конкретного контракта прочитайте [AGENTS.md](../AGENTS.md), [PRODUCT_DIRECTION.md](PRODUCT_DIRECTION.md), [ROADMAP.md](ROADMAP.md) и применимый действующий документ. Старый результат тестов нельзя использовать как доказательство готовности текущего кода.
