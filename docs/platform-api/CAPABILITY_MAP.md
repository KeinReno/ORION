# Карта возможностей для агентов

[capabilities.generated.json](capabilities.generated.json) — индекс **объявлений из кода**, а не отчёт о приёмке. Источники: каталоги компонентов, source metadata, владельцы моделей, события/подписки, permissions, паспорта, публичные пути и регистры. Компоненты вручную сюда не добавляют.

```powershell
corepack pnpm platform-map
corepack pnpm platform-map:check
corepack pnpm platform-map --component pet-care
```

Полный JSON предназначен инструментам. Агенту достаточно запроса одного компонента, его sourceDirectory, MODULE.md/AI_CONTEXT.md и соответствующего публичного контракта. До архитектурных изменений обязательны AGENTS.md и утверждённая карта владения. Компонент содержит dataModels, версию, требования, разрешения, поверхности, миграции и события; общий индекс — Core-модели, публичные контракты, UI-слоты, реестры и команды проверок.

Обновляйте карту после изменения источников. Обычный unit-набор отклоняет устаревший файл; CI отдельно вызывает platform-map:check. Генератор не читает пользовательскую конфигурацию и не обращается к БД/сети. Timestamp и текущий commit не включаются, чтобы результат был воспроизводимым.

Пути контрактов помогают найти вход, но не выдают полномочия. Статические проверки не доказывают отсутствие SQL-обходов или произвольных alias Prisma. Совместимость включения проверяется сервером; результаты тестов и ограничения среды записываются в STATUS и отчёты.
