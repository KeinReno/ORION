## Иерархия источников истины

Документы в этой папке **дополняют**, но не заменяют:
1. `AGENTS.md` и `ORION_CONSTITUTION.md`.
2. `docs/AI_REFACTOR_MIGRATION_MAP.md` — действующее разграничение Core/Base/Plugin/Bridge.
3. `docs/MODULES_AND_PLUGINS.md` и `docs/AI_FIRST_EXTENSION_ARCHITECTURE.md` — архитектура и публичные контракты.
4. `docs/PRODUCT_DIRECTION.md`, `docs/STATUS.md`, `docs/ROADMAP.md` и соответствующие ADR.
5. `MODULE.md` / `AI_CONTEXT.md` целевого домена и **фактический код на текущем коммите**.

Если есть противоречие, агент сообщает его и создаёт ADR/Extension Proposal; не исправляет архитектуру втайне.

### Не путать два вида агентов

- **ИИ-разработчик** меняет исходный код ORION; его правила — этот пакет плюс `AGENTS.md`.
- **ИИ-помощник пользователя** работает с данными ORION по разрешённому Agent Gateway/MCP; его инструкция уже существует: `docs/AGENT_MANUAL.md`.

## Ограничения текущего анализа

Ревизия сделана по доступным GitHub-репозиториям, их структурам и README/архитектурным документам, а не по полному ревью каждой строки. Для каждой предлагаемой интеграции обязателен второй, кодовый аудит **конкретного HEAD**, лицензий, зависимости, миграций, безопасности и тестов. Чужой код и реальные данные **не перенесены**.

Отдельный план пяти Grok для первой волны визуального редизайна уже лежит в `docs/KAIDEN_REDESIGN_CURSOR_5_AGENTS_2026-10-17/`. Данный пакет **не меняет** их зоны ответственности. Нельзя начинать разработку будущих модулей одновременно с их правками общих файлов без отдельного координационного решения.
