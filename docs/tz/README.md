## Что уже есть (не переделывать)

- **AI-мост** — [ADR-0007](../adr/ADR-0007-ai-bridge.md): токены агентов (`AgentToken`, sha256, срок, отзыв), `/ai/v1`, 10 scopes, журнал `AgentAuditEntry`, rate-limit, подтверждения опасного (`proposals`), задания и переписка агентов, черновики финансов, MCP stdio `scripts/orion-mcp.mjs` (22 инструмента). **Концепция «Agent Gateway» из обсуждения реализована примерно наполовину** — ТЗ-02/03 описывают только недостающее.
- **Связи** — `EntityLink` (`sourceType/sourceId/targetType/targetId/kind`) и UI `apps/web/components/entity-links.tsx`.
- **Документы** — модуль `documents` (дерево, `StorageAdapter`, превью, версии), вложения заметок.
- **Режимы** `ORION_MODE=local|server`, `LoginRateLimitGuard`, SSRF-заслон, `SNAPSHOT_MODEL_REGISTRY`, snapshot + blob-backup, WebDAV для зашифрованных бэкапов.
- **Приглашения и роли** — `WorkspaceInvite`, `WorkspaceRole` (owner/member/lead), `/invite?token=`.
- **Установщик** — NSIS, `apps/desktop/runtime/launcher.cjs` поднимает API с `ORION_MODE=local`, `HOST=127.0.0.1`.
- Заготовка `captures` в API — это **другое**: заметки-замечания, привязанные к объекту (project/task/goal/…); не путать с `orion.capture` из ТЗ-02.

## Общие правила для всех ТЗ

1. Соблюдать `Core → Contracts/SDK → Modules → Extension Points → Plugins`. Нужной точки расширения нет — остановиться, написать `NEW_EXTENSION_POINT_REQUIRED` и ADR; молча не патчить Base.
2. Инварианты модулей из [CLAUDE.md](../../CLAUDE.md): `assertMember` + `withUser`, RLS для каждой новой таблицы (структурный тест `api-rls.integration.test.ts` должен пройти), zod-схемы в `shared-types`, DTO через `toDto`, строки UI по-русски.
3. Новая workspace-модель = запись в `SNAPSHOT_MODEL_REGISTRY` (иначе процесс упадёт при старте).
4. Один concern на коммит/PR; не смешивать с редизайном и рефакторингом.
5. Гейт: `pnpm quality` + `pnpm test:integration` для API-изменений. Не заявлять «работает» без запуска; не запускать `next build` при работающем dev-сервере :3010 (используйте `pnpm typecheck`).
6. Репозиторий содержит незакоммиченные изменения других агентов (финансы, здоровье, цели) — **не трогать и не откатывать** чужие файлы; перед стартом сверить `git status`.
7. Документацию обновлять в том же PR: `docs/README.md` (таблица), `docs/ROADMAP.md`, при смене статуса — `docs/SYNC.md`/`PRODUCT_DIRECTION.md`. Не писать «реализовано» о том, чего нет.
8. Решение владельца от 2026-10-15: **оба варианта** совместной работы (общий LAN-узел и гибридная синхронизация) — целевая архитектура. Это снимает «пока не решено» в `SYNC.md`, но порядок внедрения (сначала LAN host/client) остаётся: никакой скрытой второй архитектуры sync раньше этапа 3 ТЗ-06.
