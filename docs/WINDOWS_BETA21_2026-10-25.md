Статус: **опубликован prerelease 25.10.2026** — [Windows beta 21](https://github.com/KeinReno/ORION/releases/tag/v0.1.0-windows-beta.21).

Исходники установщика: `ecd7ac73d40dced761fb87895bed5c8b8c5fd2de` (PR #66 merged). EXE: 73 888 153 байт, SHA-256 `099d76d99141753cb580df108202be84c5bb2aacb008a9754dccd2d78ad00d2d`. ## Изменения

- Общие публикации задач и базы знаний поверх существующих пространств: предпросмотр перед передачей, ограниченный набор полей, личное закрепление и независимая копия.
- По явному разрешению издателя участник может менять статус оригинальной задачи; ревизия и operationId защищают от устаревших правок и повторной отправки. После сетевого сбоя намерение сохраняется в клиенте и доступно для ручного повтора.
- Отзыв доступа, отключение модуля и восстановление источника проверяются сервером. Вложения и связанные приватные записи не передаются автоматически.
- Актуализированы проверки дневника питомцев, отключения базы знаний и навигации настроек со сворачиваемыми группами. В тестах общего доступа включён журнал серверных исключений, чтобы повторный HTTP 500 оставлял диагностическое доказательство.

Контракт и подробные проверки функции: [SHARED_PUBLICATIONS_STAGE1.md](SHARED_PUBLICATIONS_STAGE1.md), [ADR-0024](adr/ADR-0024-shared-publications.md).

## Воспроизведение проверок

Работа ведётся в отдельном managed worktree `codex/shared-publications-stage1`. Незавершённые изменения AssistantPanel, UI primitives, Prisma и Cursor rule из основной рабочей копии в выпуск не включаются. PostgreSQL на `127.0.0.1:5444`, базы только синтетические; личные данные не мигрируются.

1. `pnpm typecheck`, `pnpm lint`, `node scripts/architecture-check.mjs`, `node scripts/module-registry.mjs --check`, `node scripts/module-docs.mjs --check`.
2. Unit baseline: 1451 passed на `030c253`; последующие изменения до этого отчёта затрагивают тесты/документацию, а не продуктовую реализацию.
3. Полный integration на отдельной `orion_shared_release_test`; не запускать тяжёлую сборку одновременно с диагностическим повтором.
4. Production browser: публикации, Knowledge, дневник питомца и smoke/parity основных панелей с включёнными/выключенными плагинами. Использовать отдельную E2E_DATABASE через `scripts/e2e-local.mjs`.
5. `ORION_BUILD_TAG=v0.1.0-windows-beta.21 pnpm build:desktop-installer` после фиксации исходников. Проверить `runtime/build.json`, состав архива NSIS, отсутствие `.env`, миграцию Shared Publications, Node/PostgreSQL/Prisma и SHA-256 готового EXE.

## Границы беты

- Общие публикации работают на одном авторитетном сервере. Между независимыми серверами передача не реализована; выключенный сервер не подтверждает операции. Общая модерация текстовых правок и Android-паритет в этот выпуск не входят.
- GitHub CI не стартует из-за ограничения оплаты/расходов аккаунта (run `40134224085` на релизном commit, zero steps). Локальная проверка Windows указывается отдельно.
- Чистая физическая Windows, обновление поверх пользовательской установки, два физических устройства и установленный WebView/runtime требуют отдельной приёмки. В предыдущем проходе попытка запуска packaged runtime с отдельным профилем была отклонена автоматической проверкой (`blocked by policy`, без подробного объяснения); обход не выполняется. Упаковка NSIS и браузерные тесты не заменяют эту проверку.
- Платформенные изменения (совместимость компонентов, усиление architecture-check, сокращение boundary exceptions) отложены по решению владельца до выпуска beta 21; очередь находится в [диагностическом отчёте](PLATFORM_DIAGNOSTIC_2026-10-24.md).
