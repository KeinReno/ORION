# 12. Контекст и устойчивый редактор заметок

Дата: 2026-10-16. Продолжение c788827, ветка `redesign/kaiden-foundation-20261015`, [draft PR #1](https://github.com/KeinReno/ORION/pull/1).

## Результат

Оболочка Precision показывает название активной заметки и её реальное состояние сохранения. Новый compose явно помечен «Новая запись — сохраните явно»; создание остаётся ручным. SDK PanelObjectContext дополнен необязательным saveMode, без изменения серверной модели. Контексты разных панелей и пространств остаются изолированными по прежнему контракту этапа 10.

NotesPanel теперь сохраняет один экземпляр NoteEditor между широким и узким режимами. На широком экране список и редактор остаются рядом; на узком редактор занимает место списка и имеет кнопку «К заметкам». Прежний перенос редактора в Sheet при изменении ширины пересоздавал его с серверными полями. Смена режима больше не сбрасывает текст, Markdown, ошибку или конфликт. Это улучшение редактора действует и с прежними палитрами, не меняя сохранённые настройки темы.

Свойства заметки, календарная дата, проект, связи, доступ, вложения и упоминания используют существующие поля и компоненты. На достаточно широкой панели инспектор стоит справа рядом с текстом; на узкой занимает рабочую область, оставляя редактор смонтированным. Кнопка возврата и Escape внутри инспектора возвращают фокус к кнопке свойств. Escape из вложенного portal-диалога не перехватывается инспектором. История остаётся действующим plugin slot, исходный Markdown и команды форматирования не переписываются.

## Сохранность

Существующий NoteAutosave, CAS, debounce и действия выбора версии сохранены. Ошибка сохранения не обещает постоянного локального хранения: интерфейс просит оставить заметку открытой. Пустое название существующей заметки учитывается как несохранённое состояние, даже если контроллер ещё показывает последний успешный save. Действующий диалог отказа от правок при выборе другой заметки/закрытии списка остаётся. В самостоятельной панели собственная кнопка закрытия удерживает несохранённый редактор; браузерный beforeunload остаётся действующим.

Новые таблицы, API и зависимости не нужны. Права проверяет прежний API; ссылки/доступ и plugin slots не заменены новыми реализациями. Постоянное восстановление черновиков после перезапуска этим срезом не добавлено. Главный checkout Desktop/ORION и его данные не затронуты.

## Файлы

- `panels/NotesPanel.tsx`: стабильное размещение редактора и возврат на узком экране.

## Границы и следующие работы

Это контекст редактора и устойчивое размещение, не полная визуальная миграция всех заметок/документов. Документы, универсальный ObjectRef/ViewRef, восстановление объектов/окон и durable drafts остаются. Основной следующий приоритет по исходному плану — завершить сохранение/применение пользовательских тем и workspace overrides; вся карта находится в [этапе 11](11_REMAINING_WORK_AUDIT.md).
