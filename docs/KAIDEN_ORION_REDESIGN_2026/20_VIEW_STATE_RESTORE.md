# 20. Сериализуемое состояние представлений (задачи, заметки)

Дата: 2026-10-16. Основа: `50b2101`. Первый срез восстановления рабочего места; остальные панели, окна и прокрутка остаются открытыми.

## Контракт

`packages/shared-types/src/view-state.ts`: версионированная запись `{ v: 1, state }` на панель, ключ `orion.viewState:<userId>:<workspaceId>` в localStorage устройства (отдельно от геометрии Dockview, не синхронизируется между устройствами). Схемы строгие и ограниченные (`.strict()`, перечисления, uuid, длины): повреждённый JSON, неизвестная версия, лишние поля, неверные значения отбрасываются целиком. До 40 панелей на ключ. Миграция: сейчас существует только версия 1; чужая версия игнорируется, а не «чинится».

Хук `apps/web/lib/use-view-state.ts`: читает один раз при известных пользователе и пространстве, применяет, и только после этого начинает сохранять (стартовые значения не затирают сохранённое), запись с задержкой 300 мс.

## Что сохраняется

| Панель | Состояние |
|---|---|
| Задачи | срок, статусы, приоритеты, группировка, проект, открытая задача (id) |
| Заметки | вид (активные/архив/корзина), сортировка, группировка по проекту, теги и режим, проект, «закреплённые», открытая заметка (id) |

**Не сохраняется намеренно:** тексты и названия записей, поисковый запрос, токены, позиция прокрутки списков, черновик несохранённого ввода. Решение по черновикам: при принудительном завершении они по-прежнему не восстанавливаются (в этом срезе не добавлено и не проверялось); автосохранение задач/заметок и защита от закрытия остаются прежними.

## Недоступные объекты

Сохранённый id — только адрес. Панель открывает его через прежний API с проверкой доступа; если записи нет в загруженном (разрешённом) списке — выбор сбрасывается и показывается «Прежняя задача/заметка недоступна… удалена или нет доступа». Название и содержимое не показываются. Состояние хранится по пользователю и пространству, поэтому другое пространство/пользователь его не видит.

## Проверка

- `view-state.test.ts` — 4 сценария (круг, изоляция по пространству, отброс повреждённого/чужой версии/лишних полей/плохого id, неудачное хранилище).
- `e2e/view-state-restore.spec.ts` (default-full и plugins-off): открыть задачу и заметку → в хранилище есть id и нет названий и текста → перезагрузка возвращает обе записи → записи удалены → понятные сообщения, названий нет → повреждённое значение игнорируется, панель работает.
- Весь комплект: 819 unit-тестов (107 файлов), typecheck, lint (0 ошибок, 2 прежних предупреждения), полный browser regression на собранном web: **72/72, 3,5 мин**.
