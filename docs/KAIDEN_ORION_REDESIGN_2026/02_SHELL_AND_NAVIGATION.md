# 02. Оболочка, навигация, окна

## Три уровня навигации
1. **Глобальный rail**: включённые и видимые модули; иконки всегда видимы даже в свёрнутом виде, подписи опциональны — сохраняем ранее утверждённое поведение.
2. **Контекст пространства**: иконка + быстрое переключение предыдущий/следующий; по центральной иконке открывается поисковый список пространств, избранное, «Открыть в новом окне». Дерево проектов/объектов и закрепления.
3. **Контекст объекта**: вызванный инспектор справа с разрешёнными категориями «Свойства / Связи / История / Доступ» при наличии данных. Для задач — действующее специфицированное поведение side-by-side + autosave, не overlay.

## Объект и представление
`ObjectRef = {workspaceId, entityType, entityId}`.
`ViewRef = {ObjectRef, viewId, optional filters/sort/scale}`.
`PanelInstance = {panelId, ViewRef, windowId, active, transientUIState}`.
`Layout = {userId, deviceId, windowId, activeWorkspaceId?, panelTree, version}`.
Эти типы — логические контракты для проектирования, **не** заявление о фактической форме API. Не генерировать ID из названия. Серверная авторизация на каждом запросе.

## Правила открытия
- По умолчанию объект открывается в текущей панели/вкладке согласно настройке пользователя.
- Меню: «Открыть», «Открыть в новой вкладке», «Открыть рядом», «Открыть в отдельном окне», «Показать связи» (если модуль предоставляет view).
- «Закрыть вкладку» не удаляет объект. Несохранённый ввод: prompt/автосохранение согласно контракту типа объекта.
- Drag — дополнение; операции меню и клавиатуры имеют равную силу. `Ctrl+drag` только за handle крупного представления и только если не ломает привычные действия.
- Расположение окон синхронизировать **по устройствам отдельно**, не применять трёхмониторные координаты к ноутбуку.
- Сломанный/удалённый/недоступный view восстанавливать как понятный placeholder с действием безопасного закрытия, без раскрытия данных.

## Command Palette
Унифицированный `Ctrl+K`/существующий shortcut: поиск сущностей, фильтр по текущему пространству или доступным, явные команды. Приоритет локального текстового поиска. AI semantic search позднее и отдельно; права доступа действуют также в результатах.

## UX-ограничения
Текст ограничен комфортной шириной, графы/таблицы используют холст. На узких экранах панели переключаются без тесного двухколоночного режима. Управление клавиатурой, подсказки, ARIA names, видимый focus, reduced motion. Система состояния показывает текущий workspace владельца каждой вкладки и понятный признак сохранения.

## Существующий фундамент
Текущий `../FRONTEND_WORKSPACE_SPEC.md` прямо указывает на Dockview и Tauri WebviewWindow. Прежде чем кодировать, проверить их runtime-состояние и API; наращивать типизированные представления поверх них, а не внедрять альтернативный docking manager.
