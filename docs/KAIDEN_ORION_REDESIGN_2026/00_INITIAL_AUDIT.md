# 00. Стартовый аудит — первоначальная проверка репозитория
Дата: 2026-10-15. Статус: начат, **не завершён**. Основан на содержимом репозитория; живой экран, локальная сборка и тесты на этом этапе не запускались.

Обновление 2026-10-16: выполнен runtime/code baseline и первый совместимый token-срез.
Подробные результаты и ещё открытые gates: [06_FOUNDATION_V1.md](06_FOUNDATION_V1.md).
Исходные пункты ниже сохранены как запись первоначального обследования.

## Подтверждённые факты
- `package.json`: pnpm 9.12, Next/Nest/Tauri монорепозиторий, доступны команды `typecheck`, `lint`, `test`, `architecture-check`, `plugin-contract-check`, `build:desktop-export`.
- `README.md`: в существующем продукте есть dockable Workbench, отдельные окна панелей desktop, управление модулями, глобальный поиск и несколько изолированных пространств.
- `docs/FRONTEND_WORKSPACE_SPEC.md`: Dockview уже поддерживает панельные layout, Tauri `WebviewWindow` открепляет целые панели; подвиды проекта не являются полноценными зарегистрированными панелями. Существующий UX согласован отдельно.
- `docs/UI_AUDIT_2026-10-11.md`: в предыдущем живом аудите исправлены проблемы стилей, обзора, задач, заметок, календаря и плагинов; результаты проверок относятся **к состоянию на дату того аудита**, не к текущей ревизии.
- `docs/PRODUCT_DIRECTION.md` и `docs/SYNC.md`: WebDAV не является доказанной двусторонней live sync. Проектный редизайн не расширяет полномочия межпространственного доступа.
- `AGENTS.md`, `ORION_CONSTITUTION.md`: запрещено совмещать архитектурную экстракцию с UX-редизайном; нельзя нарушать направления импортов и менять ownership без ADR.

## Что ещё необходимо проверить прежде, чем писать код
1. Актуальные файлы оболочки (Next layout, sidebar, panel registry, Dockview bindings, инспектор).
2. Существующие theme tokens / CSS variables / persisted appearance settings; нельзя утверждать, что они отсутствуют, на основании нулевых результатов code search.
3. Панели модулей, UI slot contracts, plugin styles, различия browser и Tauri.
4. Действующие screenshot/E2E тесты и baseline современного UI.
5. Поведение при переключении пространства и при открытых нескольких окнах.
6. Локальные настройки и backup до изменения схемы предпочтений.

## Начальное решение
**Не переписывать Shell целиком.** Первый кодовый срез после аудита — минимальная совместимая token foundation, с флагом обратимого включения. Нельзя запускать массовую миграцию компонентов до подтверждения parity.
