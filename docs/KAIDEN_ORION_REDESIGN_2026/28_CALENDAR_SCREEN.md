# 28. Визуальная миграция: календарь

Дата: 2026-10-17. Основа: `56e738b`. Пятый вертикальный срез фазы 5 (проекты 24, задачи 25, заметки 26, документы 27). Источники, события, drag/resize/перенос, открытие объектов (этапы 17 и 21), вид после перезапуска (этап 20) и plugin slot `calendar.toolbar` не менялись. Срез небольшой и не закрывает полную миграцию календаря.

## Что изменилось

- **Сегодня заметно в сетке месяца.** Число сегодняшнего дня — заполненная метка (акцент и цвет текста на акценте) с `aria-current="date"`, а не только цветное число. Прежнее правило из кода сохранено: числа соседних месяцев не бледнеют, контраст не падает.
- **Источники на узкой ширине** (<640 px): шесть цветных чипов раньше занимали 2 ряда над сеткой. Теперь это один пункт «Источники · N из M» (нативный `details`, клавиатура штатная); внутри те же переключатели `aria-pressed`. На широкой ширине чипы стоят в строке, как раньше. Чипы плагина (`calendar.toolbar`, например «Ссылка») остаются видимыми.

## Функциональное сравнение

Месяц/неделя/день/список, переход по периодам и к дате, переключатели источников, поиск по календарю, быстрые действия «Событие» и «Задача / заметка», справка по клавишам, открытие задач и заметок через контекстное меню (этап 21) и меню в списке (этап 17), перенос и изменение размера, повторы, области, вид после перезагрузки — не менялись; сценарии `calendar-object-opening`, `calendar-grid-opening`, `panels`, `view-state-restore` проходят.
