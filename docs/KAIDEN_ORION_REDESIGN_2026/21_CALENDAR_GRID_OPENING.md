# 21. Открытие исходных объектов из сеток календаря

Дата: 2026-10-16. Основа: `c9afdbb`. Закрывает остаток этапа 17 (сетки месяц/неделя/день).

## Решение

В плотных сетках кнопка «⋯» на каждой плашке не помещается, поэтому команды вызываются из **контекстного меню элемента**: правая кнопка, клавиша Menu или Shift+F10 на сфокусированной плашке. Меню содержит те же три действия, что везде: новая вкладка / рядом / отдельное окно.

- `packages/ui` calendar: необязательный `onItemContextMenu(id, {x, y})`; Pill (месяц, день-полоса, неделя/день) и блоки временной сетки сообщают о запросе. Календарь не знает доменных команд. Клавиатурный вызов якорится к самой плашке. В временной сетке правая кнопка больше не начинает перетаскивание (`e.button !== 0`); сами перенос и изменение размера не менялись.
- `apps/web/components/object-open-popup.tsx` — меню в точке: фокус на первом пункте, ↑/↓, Enter, Escape возвращает фокус плашке, клик вне закрывает. Проверки те же, что у ObjectOpenMenu (текущее пространство, зарегистрированное представление, доступность открытия).
- CalendarPanel показывает меню только для задач и заметок включённых источников. События, платежи и дни рождения меню не получают, их обычное поведение прежнее.

## Проверка

`e2e/calendar-grid-opening.spec.ts`, default-full и plugins-off: в видах Месяц (мышь), Неделя (Menu), День (Shift+F10): меню → первый пункт в фокусе → Escape возвращает фокус плашке → «Открыть рядом» с клавиатуры (то же название задачи, вид календаря сохранён) → заметка «в новой вкладке» → возврат в календарь; повторное открытие не плодит вкладок (по одной на задачу и заметку); у события меню нет; в API по одной записи, `dueAt` задачи не изменился.

Полный набор: typecheck, 819 unit-тестов, lint (0 ошибок, 2 прежних предупреждения), полный browser regression на новой сборке: **74/74, 3,6 мин**. Один раз в журнале API встретился отказ `userPreference.upsert` по уникальному `userId` (гонка параллельных первых GET настроек у нового пользователя); тест это не затронуло, причина не исследовалась и вне данного среза.

## Границы

Перетаскивание и изменение размера на физическом устройстве, touch (долгое нажатие), документы/списки в календаре и Tauri не проверялись. Календарное состояние вида (месяц/неделя/дата) после перезапуска не восстанавливается.
