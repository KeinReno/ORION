На карте Goals выбранный узел за пределами поля автоматически возвращается в видимую область; для уже видимого камера сохраняется. Прогон браузерного Goals Atlas: два исходных сценария прошли, третий после учёта перемещения камеры прошёл отдельно; сразу после создания проверяется видимость нового узла, после «Вписать всё» — доступность предыдущего. Проверялись отдельные временные база и профиль.

Оболочка отказывает при занятых портах и принимает готовность только от API и PostgreSQL внутри собственного Windows Job; создание процесса происходит приостановленным с назначением Job до возобновления. Пройдено 23 Tauri unit tests, 6 helper ignored, включая проверки отказов Job, принадлежности, окружения и логов. Полноценный Tauri startup не подтверждён: автоматическая проверка отклонила запуск и остановку изолированного нативного smoke с ответом `blocked by policy`. Подтверждение GUI и установленного приложения остаётся необходимым.

Извлечённый runtime исправленного NSIS запущен через отдельный benchmark Job на новом временном профиле; API/БД достигли `database=ok`, принадлежность listener к тестовому Job проверена, временный профиль очищен. Это проверка комплекта, а не новой Tauri оболочки.

База и API всё ещё запускаются JavaScript launcher; безопасный импорт Classic не готов. Этот билд не доказывает полный перенос runtime на Rust и не разрешает миграцию рабочих данных. Предыдущий установщик 0.1.43 содержит исправленные здесь проблемы и должен считаться заменённым.
