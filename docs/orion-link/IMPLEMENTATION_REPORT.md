# Что сделано в LINK-01A и LINK-01B

Слушатель `SendLink` (`apps/api/src/send/`) поднимается только после включения. Он использует сертификат узла, mDNS с типом `orion-send` и существующий перебор адресов. Сопряжение взаимное: код на экране и обратная проверка сертификата. Передача файлов и папок идёт блоками, с SHA-256, паузой, отменой и продолжением после перезапуска процесса.

Панель `SendPanel`, методы `ApiClient` и действия «Отправить на устройство» / «Отправить копию» в документах, заметке и задаче. Копия записывается файлом и не создаёт запись в чужом пространстве.

Контракты проекта и Agent Link описаны типами и не исполняются. Hybrid Sync не подключался к этому порту. Совместимый приём LocalSend v2 есть и по умолчанию выключен.

Режим Host/Client, файл доверенных устройств хоста и порт 4443 не заменялись.
