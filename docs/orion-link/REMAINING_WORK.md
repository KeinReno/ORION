# Что осталось после Orion Send

1. Прогон на двух физических Windows в одной сети, с VPN и без интернета. До него продукт нельзя называть проверенным на ваших компьютерах.
2. Замер передачи файла больше 1 ГБ: память, скорость, обрыв посередине.
3. Orion Sync поверх этого канала не делался. Hybrid Sync по-прежнему ходит к авторитетному узлу. Связывать два независимых PostgreSQL этим портом нельзя: появится два источника правды.
4. Экспорт проекта описан контрактом `projectBundleContractSchema` и не применяется.
5. Agent Link ограничен именами событий и схемой задания. Задания не исполняются, лента активности не имитируется.
6. LocalSend: адаптер не проверен с Android-приложением. Лицензия протокола позволяет описать свой клиент; исходники LocalSend в репозиторий не копировались.
7. Установщик Windows beta этим изменением не собирался и не публиковался.
