# Orion Link — транспорт для Orion Send

Orion Link в этом выпуске — это уже существующий LAN-узел (mDNS, перебор подсети, TLS с закреплением сертификата, сопряжение шестизначным кодом) плюс отдельный слушатель передачи. Он не заменяет Hybrid Sync и не открывает API пространств.

Слушатель включается пользователем в панели «Orion Send». Пока он выключен, порт закрыт. По умолчанию это порт 4455, протокол `orion-send` версии 1, DNS-SD `_orion-send._tcp`. Режим Host/Client на порту 4443 не меняется: токены Send лежат в `send-peers.json`, а не в `lan-devices.json`.

Два компьютера в режиме «Локальный» находят друг друга этим портом. Один не обязан становиться хостом, другой — клиентом. Доверие к устройству не даёт права получить файл: каждый входящий набор подтверждается отдельно.

Поиск идёт через физический адаптер в первую очередь (тот же разбор интерфейсов, что у LAN). VPN-адаптеры и адреса Tailscale — дополнительный маршрут по кнопке «Искать в подсети» и при обычном поиске пиров Tailscale. Постоянного сканирования подсети нет.
