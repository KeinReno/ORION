# Отчёт испытаний Orion Send

Автоматические проверки: `pnpm exec vitest run packages/shared-types/src/orion-send.test.ts apps/api/src/send/send-link.test.ts`.

На момент отчёта 12 тестов прошли. Два процесса на 127.0.0.1: обнаружение визиткой, сопряжение кодом, передача файла и папки в обе стороны, отказ, отзыв, пауза и новый процесс отправителя, перезапуск получателя, SHA-256, нехватка места, путь `../`, чужая версия, повтор request-id, выключенный слушатель, подмена сертификата, 100 файлов. Токен Send не попадает в `lan-devices.json`.
